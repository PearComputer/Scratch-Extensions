IndexedDB Storage
ID: indexeddbstorage By: Sakura Matsumoto (generated by Super Z) License: MIT

## Description
Store large amounts of data persistently using IndexedDB. This extension functions similarly to local storage but offers significantly more space and is binary-safe.

## Features
- Persistent data storage across sessions.
- Larger storage capacity compared to standard local storage.
- Binary-safe data handling.

## Usage
This extension must be run unsandboxed in your Scratch 3 environment.
```js
if (!Scratch.extensions.unsandboxed) {
    throw new Error("IndexedDB Storage must be run unsandboxed");
}
```
